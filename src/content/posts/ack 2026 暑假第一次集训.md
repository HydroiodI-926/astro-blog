第三题稍微提一下，其实只用到了去重，c++的话用set和unordered_set都可以
```cpp
unordered_set<string> st;
string s;

void solve() {
	while(cin>>s&&s!="0"){
		if(st.find(s)==st.end()){
			st.insert(s);
			cout<<s;
		}
	}
}
```
