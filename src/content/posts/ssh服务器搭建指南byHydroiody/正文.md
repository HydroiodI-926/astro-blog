首先你需要以下准备：
1. 一台做服务端的主机，系统版本为ubuntu-24.04，主机有网卡
2. 一台作为客户端的笔记本
## 服务端准备
### 联网
校园网亲测可行，如果是ubuntu这种配有交互式界面的发布版操作会非常容易，连接莞工全光无线后就会自动跳转到登录界面，用学号密码登录就可以了
路由器或者有限网络也可以使用，稍后有详细讲解
### 在ubuntu主机上准备ssh服务
在终端输入以下命令
```bash
sudo apt update
sudo apt install -y openssh-server
sudo systemctl enable --now ssh
```
以上代码用于搭建ssh服务
其中，“enable”会设置成开机自启
```bash
sudo systemctl status ssh
```
这行代码会输出当前ssh服务是否正常工作
### 查询该服务器ip 
```bash
ip a
```
一般来讲，会显示三点，分别是lo 有线网卡 无线网卡
如果lo 的inet是192开头的，可以直接使用，如果是127.0.0.1，则需要使用下面网卡的ip地址（inet后面的信息）如果都没有inet地址，则需要激活网卡
### \*激活网卡
一般来讲，安装ubuntu系统的时候就会连接网络了。不过没连上，可能是因为网卡没有激活
```bash
# 激活有线网卡
sudo nmcli device connect "你的有线网卡名称"
```
如果没有连网线，不需要执行这一步骤
```bash
# 激活无线网卡
sudo nmcli device wifi connect "wifi名称（ssid）" password "密码"
```
如果没有密码，可以省略密码部分
```bash
sudo nmcli device wifi connect "wifi名称（ssid）"
```
如果重启后ip又不见了，要配置netplan，此处不详细阐述
之后可以ping一个网站试试，或者直接使用浏览器
### 开启ufw防火墙
```bash
sudo ufw allow ssh
sudo ufw enable
```
同理，enable设置了开机自启
```bash
password
```
修改当前用户密码（可选）
### 设置不自动休眠
```bash
sudo systemctl mask sleep.target suspend.target hibernate.target hybird-sleep.target
```
sleep.target 总控制项
suspend.target 挂起 屏蔽数据存入内存
hibernate.target 休眠 屏蔽数据存入硬盘
hybird-sleep.target 混合睡眠
恢复操作如下
```bash
sudo systemctl unmask sleep.target suspend.target hibernate.target hybird-sleep.target
```
```bash
system status "上面的名词"
```
验证
```bash
gsetting set org.gnome.desktop.session idle-delay 600
```
最后可以设置屏幕黑屏(不执行任何操作10分钟后)，省电
## 客户端
### 远程操作服务端
通过cmd或者powershell
```
ssh "服务端此时的用户名"@"服务器ip"
```
输入服务端上该用户名的密码
之后就可以通过笔记本上的终端操作服务端了
