# `main.py` 逐行代码解释

> [材料依据] 本文逐行对应同目录下的 `main.py`，源码范围为第 1～268 行。  
> [模型补充] 文中关于 RetinaFace、Anchor、IoU、NMS 和 ONNX Runtime 的背景说明属于通用工程知识，用于帮助理解源码，不代表源码中显式写出了这些理论。

## 一、程序整体作用

这份程序使用 OpenCV 从摄像头读取画面，通过 ONNX Runtime 运行 RetinaFace 人脸检测模型，得到每张人脸的位置与置信度。程序随后绘制检测框，选择面积最大的人脸作为当前目标，并计算目标中心相对画面中心的水平、垂直偏差。

整体数据流如下：

```text
摄像头画面
  → 等比例缩放与填充
  → 转换为 ONNX 输入张量
  → RetinaFace 推理
  → 解码人脸框
  → 置信度过滤
  → NMS 去除重复框
  → 绘制人脸与中心偏差
```

## 四、理解这份代码时最重要的边界

1. **检测不等于身份识别**：程序只知道哪里有人脸，不知道这个人是谁。
2. **逐帧选最大框不等于稳定跟踪**：多人交叉或远近变化时，目标可能切换。
3. **关键点输出被忽略**：`loc, conf, _ = outputs` 中第三项通常包含五个人脸关键点，但当前程序没有使用。
4. **预处理必须与模型一致**：RGB/BGR 顺序、均值、方差系数和先验框配置都不能随意修改。
5. **CPU 推理是明确指定的**：即使安装了 GPU 运行环境，当前 `providers` 设置也只会使用 CPU。
6. **摄像头分辨率只是请求值**：最终实际画面尺寸由摄像头和驱动决定，代码使用 `frame.shape` 获取真实尺寸是正确做法。
