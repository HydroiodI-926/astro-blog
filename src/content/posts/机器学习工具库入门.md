# NumPy基础操作
##### numpy是Python中科学计算的基础包。它是一个Python库，提供多维数组对象、各种派生对象(例如掩码数组和矩阵)以及用于对数组进行快速操作的各种方法，包括数学、逻辑、形状操作、排序、选择、1/0、离散傅里叶变换、基本线性代数、基本统计运算、随机模拟等等。numpy的部分功能如下:
 - ndarray，一个具有矢量算术运算和复杂广播能力的快速且节省空间的多维数组
 - 用于对整组数据进行快速运算的标准数学函数(无需编写循环)
 - 用于读写磁盘数据的工具以及用于操作内存映射文件的工具
 - 线性代数、随机数生成以及傅里叶变换功能
 - 作为**科学计算生态桥梁**，用于集成由C、C++、Fortran等语言编写的代码的API， **在 ROS 中可直接用于消息字段、传感器数据、算法结果的零拷贝转换**

## ndarray的特性
### 多维性

| 名称  | 维度  | 示例                   | 备注             |
| --- | --- | -------------------- | -------------- |
| 标量  | 0维  | `5`，`3.14`           | 单个数字，无行列       |
| 向量  | 1维  | `[1, 2, 3]`          | 只有行或列（一维数组）    |
| 矩阵  | 2维  | `[[1, 2], [3, 4]]`   | 严格的行列结构（二维表）   |
| 张量  | ≥3维 | `[[[1, 2], [3, 4]]]` | 高阶数组（如 RGB 图像） |

### 同质性
一个多维数组中的所有元素数据类型一致，如果定义时出现了一个字符串，那么会将其他元素强制转换为字符串；如果在整数中出现浮点数，那么则会转换为浮点数（str > float > int）
### 高效性
### 属性：
- 尺寸 .shape
- 维度 .ndim
- 总元素个数 .size
- 元素类型 .dtype
- 矩阵转置 .T
- 单个元素占用的内存字节数 .itemsize
- 总内存占用量 .nbytes
- 内存存储方式(是否连续存储) .flags
## 数组的创建

| 用途             | 方法                                                         |
|------------------|--------------------------------------------------------------|
| 基础构造         | `np.array()` ， `np.copy()`                                   |
| 预定义形状填充   | `np.zeros()` ， `np.ones()` ， `np.empty()` ， `np.full()`    |
| 基于数值范围生成 | `np.arange()` ， `np.linspace()` ， `np.logspace()`           |
| 特殊矩阵生成     | `np.eye()` ， `np.diag()`                                     |
| 随机数组生成     | `np.random.rand()` ， `np.random.randn()` ， `np.random.randint()` |
| 高级构造方法     | `np.array()` ， `np.loadtxt()` ， `np.fromfunction()`         |

 1. 基础构造: 适用于手动构建小规模数组或复制已有数据
 2. 预定义形状填充:用于快速初始化固定形状的数组(如全0占位、全1初始化)
 3. 基于数值范围生成: 生成数值序列，常用于模拟时间序列、坐标网格等
 4. 特殊矩阵生成:数学运算专用
 5. 随机数组生成:模拟实验数据、初始化神经网络权重等场景
 6. 高级构造方法:处理非结构化数据(如文件、字符串)或通过函数生成复杂数组

## 矩阵运算
```python
# 广播机制原理
# 1
arr1 = np.ones((4,5))
print(arr1)
print(arr1 + 3)
print(arr1 * 2)
print(arr1 - 1)
print(arr1 / 2)
print((arr1 + 1) ** 3)  # 矩阵的标量的计算，标量会扩充成与该矩阵相同大小，元素全为该标量的矩阵，然后对应元素进行有关运算
# 2
a = np.array([[1,2,3],[4,5,6]])
b = np.array([1,1,1])
print(a+b)  # 矩阵（mxn）与向量（n）进行计算时，向量首先会扩充成1xn的矩阵再以第一行的数据扩充成mxn的数据
# 3
a = np.array([3,2,1,4])
b = np.array([[1],[2],[3]])
print(a+b)  # 行向量与列向量进行运算会相互扩充
# 只有当两个数组的维度从后向前逐一比较时，对应维度要么相等，要么其中一个为 1（或缺失，视为 1），否则就会报错。

# 内积
a = np.array([1, 2, 3, 4], dtype=np.int32)
d = np.arange(6, 10)
np.dot(a, d)
# 矩阵乘法
g1 = np.array([[1, 2],[3, 4]])
g2 = np.array([[2, 0],[0, 2]])
g1 @ g2 # or np.matmul(g1, g2)
```
## 统计函数（函数结果返回一个数）
1. np.sum 求和 np.mean 取平均值 np.median 求中位数  np.var 求方差 np.std求标准差
2. np.max 求最大值 np.argmax求最大值的索引(最小值同理)
## 比较函数（函数结果返回一个bool值(数组)）
1. np.greater / np.less / np.equal  比较两个**形状相同**的数组对应元素的大/小/等于 也可以与一个标量比较（遵从广播机制）
```python
arr1 = np.array([1,2,3,4,5])
arr2 = np.array([5,4,3,2,1])
print(np.greater(arr1,arr2))
print(np.equal(arr1,arr2))
print(np.less(arr1,arr2))
```
1.  np.logical_and / np.logical_or对两个**形状相同**的数组对应元素进行逻辑运算,也可以与一个标量比较（遵从广播机制）np.logical_not对一个数组的bool值取反
2. np.any 检查一个数组元素是否至少有一个元素的bool值为true;np.all 检查一个数组的元素是否全为true
3. **np.where**自定义条件比较函数（联系c语言的三元运算符）
```python
np.where(condition, x, y)
```
会对数组元素一一进行条件判断，真值替换为x值，假值替换为y值（即自定义条件、真值和假值的数值）
```python
arr = np.array([1,2,3,4,5])
print(np.where(arr<3,arr,0))  # 对arr中的元素进行逐一排查，小于3的不变，大于等于3的变为0

# 同时支持嵌套
score = np.random.randint(50,100,20)
print(score)
print(np.where(
    score>=80,'优秀',np.where(
        score>=60,'及格','不及格'
    )
))  # select(条件数组,结果数组,default=默认值)可以达成同样的条件

```

# Pandas基础操作
##### Pandas 是 Python 数据分析工具链中最核心的库，充当数据读取、清洗、分析统计、输出的高效工具。Pandas 提供了易于使用的数据结构和数据分析工具，特别适用于处理结构化数据，如表格型数据(类似于Excel表格)。Pandas 是数据科学和分析领域中常用的工具之一，它使得用户能够轻松地从各种数据源中导入数据，并对数据进行高效的操作和分析。Pandas是基于NumPy构建的专门为处理表格和混杂数据设计的Python库，核心设计理念包括:
 - 标签化数据结构:提供带标签的轴
 - 灵活处理缺失数据:内置NaN处理机制
 - 智能数据对齐:自动按标签对齐数据
 - 强大IO工具:支持从CSV、Excel、SQL等20+数据源读写
 - 时间序列处理:原生支持日期时间处理和频率转换
## 核心数据结构

| 比较维度        | Series（序列）        | DataFrame（数据框）                      | 说明                       |
| ----------- | ----------------- | ----------------------------------- | ------------------------ |
| 数据结构类型      | 一维数组              | 二维表格（类似电子表格或SQL表）                   | 基础数据结构之一                 |
| 数据维度        | 1 维               | 2 维                                 | 使用 `.ndim` 可查看           |
| 索引结构        | 单一索引              | 行索引 + 列索引                           | DataFrame 具有更复杂的结构       |
| 元素访问方式      | `series[index]`   | `df[col][row]` 或 `df.loc[row, col]` | DataFrame 可按行列定位访问       |
| 数据类型        | 同一列数据类型（一般为同类型）   | 不同列可以为不同的数据类型                       | 异构结构                     |
| 构造方式        | `pd.Series(data)` | `pd.DataFrame(data)`                | data 可以是字典、列表、数组等        |
| 常见用途        | 表示一列数据（如某列成绩、价格等） | 表示整个表格、数据集                          | DataFrame 更适合建模分析        |
| 与 NumPy 的关系 | 类似一维的 ndarray     | 类似二维的 ndarray                       | 都是基于 NumPy 构建            |
| 标量操作        | 支持广播操作            | 同样支持广播操作                            | 与 NumPy 类似               |
| 作为子结构       | 可作为 DataFrame 的一列 | 可由多个 Series 组成                      | Series 是 DataFrame 的组成部分 |
