# 程序入口

| 语言     | 是否必须固定入口                                         |
| ------ | ------------------------------------------------ |
| C++    | 必须有全局 `main()`                                   |
| Java   | 必须有类中的 `public static void main(...)` 才能作为普通程序入口 |
| Python | 不必须有 `main()`，脚本可以直接从上到下执行                       |

- cpp的程序入口必须是独立的全局main()函数，负责启动对象和调用程序逻辑
- java只有方法的概念，没有裸露的/脱离类存在的函数，因此需要主函数作为程序入口
- python并不强调入口概念

Java主入口
```java
public class demo {
    public static void main(String[] args){
        System.out.println();
    }
}
```

c++主入口
```cpp
int main(){
	std::cout<<"";
	return 0;
}
```

Python主入口
```python
def main():
	print()

if __name__ == "__main__":
	main()
```

## 类的普通对象创建
| 语言     | 普通对象创建                         |
| ------ | ------------------------------ |
| Java   | 通常 `new Student()`             |
| C++    | `Student s;` 或 `new Student()` |
| Python | `Student()`，内部调用 `__new__`     |
其中java中的 new的的工作流程如下：
	Java new
	   ↓
	创建对象所需空间
	   ↓
	对象初始化
	   ↓
	执行构造方法
	   ↓
	得到对象引用

例如：

```java
Student s = new Student();
```

可以拆成：

```
Student s      → 声明引用变量
new            → 创建对象
Student()      → 构造方法完成初始化
=              → 让 s 引用该对象
```

# 对象自身引用
一般情况下，类的方法里面可能会定义与属性变量名相同的变量名，那么此时就会和类属性冲突，一般会符合就近原则，即方法中默认认为同名的变量的意义是局部定义的意义，通过关键字，以便区分同名的属性和局部变量。Java c++ 都是用this，并且不需要在代码中写出来，而python的self需要在方法的参数表里面写出来，本质都是**在类的方法内部明确指向当前对象的成员**，解决局部变量、参数和成员变量同名时的歧义。
```java
public class Student {   
    private int age;  
    public void setAge(int age){  
        this.age=age;  
    }  
}
```

# 封装

封装：**隐藏对象内部的实现细节，只向外暴露必要、统一、受控的访问接口。**

也可以说

$$\boxed{封装 = 隐藏实现 + 暴露接口 + 控制访问}$$

封装可以带来两个好处：**降低耦合**和**便于修改内部实现**。只要对外接口不变，内部实现可以随便调整。

## 封装层次（针对java）

```
方法
↓
类 / 接口
↓
包
↓
模块 / 系统
```
是一种由小到大的封装层次，其中：
- **方法**：封装一段具体功能或行为的实现细节。
- **类**：封装对象的**状态（属性）和行为（方法）**。
- **接口**：主要封装的是一组**行为规范/能力约定**，强调“能做什么”，而不是“怎么做”。
- **包（package）**：把相关的类和接口组织在一起，同时配合 `public`、包访问权限等形成更大的可见性边界。

## Java
### 1.控制修饰符

通过 **控制修饰符** 来控制类、方法、成员变量等的可见性和访问范围

|修饰符|同一个类|同一个包|不同包的子类|不同包的普通类|
|---|--:|--:|--:|--:|
|`public`|✅|✅|✅|✅|
|`protected`|✅|✅|✅|❌|
|不写（default）|✅|✅|❌|❌|
|`private`|✅|❌|❌|❌|

private 外界只是不能显式调用对应的方法，变量等，通过其他给定的方法等可以间接使用或者修改private修饰的方法和变量

### 构造方法/构造器/构造函数
#### 特点
1. 方法名与类名相同，大小写也要一致
2. 没有返回值类型，连void都没有
3. 没有具体返回值
