# 程序入口

| 语言     | 是否必须固定入口                                         |
| ------ | ------------------------------------------------ |
| C++    | 必须有全局 `main()`                                   |
| Java   | 必须有类中的 `public static void main(...)` 才能作为普通程序入口 |
| Python | 不必须有 `main()`，脚本可以直接从上到下执行                       |

- cpp的程序入口必须是独立的全局main()函数，负责启动对象和调用程序逻辑
- java只有方法的概念，没有裸露的/脱离类存在的函数，因此需要主函数作为程序入口
- python并不强调入口概念

Java主入口
```java
public class demo {
    public static void main(String[] args){
        System.out.println();
    }
}
```

c++主入口
```cpp
int main(){
	std::cout<<"";
	return 0;
}
```

Python主入口
```python
def main():
	print()

if __name__ == "__main__":
	main()
```
